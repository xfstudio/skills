## API Key 核心规则摘要（两站规则基本一致，仅控制台入口域名不同）

来源：国内站 [API Key 管理](https://cloud.tencent.com/document/product/1823/130090) / 国际站 [API Key Management](https://www.tencentcloud.com/document/product/1300/78949)

- API Key 长期有效，通过请求头 `Authorization: Bearer <key>` 携带。
- 单个主账号默认最多创建 **50 个** API Key（不含 Coding Plan / Token Plan 生成的 Key）。
- **访问范围**：全选（所有模型和服务）/ 限定范围（勾选具体模型对应的推理服务接入点）。平台为每个模型创建一个默认在线推理服务，勾选模型即等同于授权该模型级访问。
- **额度限制**（默认不开启）：可设日/月/总额度三种周期，超限后调用失败（免费包用量不计入）。切换限额策略或改月度生效日会清零历史用量重新累积。
- Key 名称和 Key 值创建后**不可修改**；删除后立即失效且不可恢复，会触发账号身份校验。
- Key ID 用于账单分账查询。
- 使用建议：按用途拆分 Key（开发/测试/生产）、最小权限原则、定期轮换、及时禁用/删除闲置 Key。
- **两站的 API Key 互相不通用**：国内站创建的 Key 只能用于 `tokenhub.tencentmaas.com` 域名调用，国际站创建的 Key 只能用于 `tokenhub-intl.tencentcloudmaas.com` 域名调用，混用会导致鉴权失败。
